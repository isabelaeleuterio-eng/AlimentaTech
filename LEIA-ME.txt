AlimentaTech — pacote para GitHub/Vercel

Conteúdo:
- index.html: site do AlimentaTech
- assets/: imagens do projeto e fotos reais de montagem
- assets/videos/projeto-final.mp4: vídeo final do projeto
- assets/videos/montagem-1.mp4 e montagem-2.mp4: vídeos das etapas de construção

Antes de publicar:
1. Confira o site localmente abrindo index.html no navegador.
2. Verifique se as fotos e vídeos aparecem corretamente.
3. Se estiver tudo certo, copie os arquivos para a pasta do repositório conectado à Vercel.
4. No terminal dessa pasta, execute:
   git add index.html LEIA-ME.txt assets
   git commit -m "Atualiza registros reais do AlimentaTech"
   git push

A publicação só acontece depois que o repositório for atualizado e a Vercel concluir o deploy.
