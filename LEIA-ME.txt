ALIMENTATECH — GRUPO 11
Pacote atualizado para GitHub e Vercel

CONTEÚDO
- index.html: página principal revisada.
- assets/: fotos técnicas e vídeo do protótipo.

PUBLICAR PELO GITHUB (recomendado)
1. Extraia este ZIP.
2. Copie index.html, LEIA-ME.txt e a pasta assets para a pasta local que está conectada ao repositório AlimentaTech.
3. Confirme que index.html e assets estão no nível principal da pasta.
4. No terminal, dentro da pasta do projeto, execute:
   git add index.html LEIA-ME.txt assets
   git commit -m "Atualiza site AlimentaTech"
   git push
5. Se o repositório estiver conectado ao projeto correto na Vercel, o deploy será iniciado automaticamente.
6. Aguarde o deploy terminar e abra o site publicado para conferir fotos, vídeo, navegação e versão para celular.

IMPORTANTE
- Não apague a publicação anterior até confirmar que a nova versão está funcionando.
- A página descreve o projeto como protótipo em desenvolvimento; não afirma que todos os testes foram concluídos.
- A demonstração interativa no site é ilustrativa e não representa conexão ao vivo com o Arduino.
- O sensor ultrassônico detecta proximidade, mas não identifica individualmente o animal.
- Revise o enquadramento de novos vídeos antes de publicá-los para evitar expor pessoas sem necessidade.
